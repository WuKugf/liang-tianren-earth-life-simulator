# 梁添任的地球生活模拟器

以「梁添任」为主角的 3D 网页生活模拟：清晨从奥园中央墅出发，穿过十字街的烟火气，去金榜小学上学，
跳绳、投篮、逛夜市，看天色从黄昏走到夜晚。

- **纯静态站点**：原生 ES Module + importmap，three.js 0.160 走 CDN，**没有 npm 依赖、没有构建步骤**
- **第三人称**：相机始终跟随在角色身后，滚轮缩放最近到 3.4m，不做第一人称
- **电影感启动页**：黄昏环绕镜头、电影黑边、衬线大标题、金色菜单，可选「剧情模式 / 普通模式」
- **程序化生成**：建筑、街道、植被、人物全部代码建模；背景音乐与音效由 WebAudio 实时合成，仓库里没有任何音频/贴图资源

## 功能

- **三个可切换场景**：生活区（含运动训练场与西侧十字街夜市）、玉东新区金榜小学、奥园中央墅，按 `1 / 2 / 3` 切换
- **昼夜与天气**：时间系统驱动天空、雾、阳光角度与强度、夜晚星空；`T` 键切换 ×1 / ×2 / ×4 / ×8 流速
- **剧情模式**：7 步生活任务（和街坊打招呼 → 跳绳 10 个 → 学习 1 小时 → 投进 2 球 → 傍晚逛夜市 → 回家看电视 → 睡觉），左侧任务卡实时更新
- **小游戏**：跳绳（节奏蓄力）与投篮（蓄力 + 出手判定），有个人纪录
- **生活细节**：客厅电视 4 个自绘频道、NPC 沿路线散步并转身挥手对话、换装面板、体力条
- **程序化音频**：白天/夜晚两套 BGM，鸟鸣虫鸣、夜市人声，脚步、跳跃、跳绳节拍、投篮出手与空心入网、电视开关、任务完成等音效
- **本地存档**：时间、天数、场景、位置、服装、模式、剧情进度、纪录，每 6 秒自动保存

## 运行

浏览器不允许 `file://` 直接加载 ES Module，**必须用本地静态服务器**打开：

```powershell
node server.cjs 8080        # 项目自带的零依赖静态服务器
# 或
python -m http.server 8080
```

然后访问 <http://localhost:8080>。Windows 下也可以直接双击 `启动预览.bat`（会自动尝试 `node`，再尝试 `python`）。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动 |
| Shift | 跑步（消耗体力） |
| 空格 | 跳跃；小游戏里蓄力 / 跟拍 |
| 鼠标拖动 / Q E | 旋转视角（靠近互动点时 `E` 优先为互动） |
| 滚轮 | 缩放视角（始终第三人称，最近 3.4m） |
| E | 与提示点互动（聊天 / 跳绳 / 投篮 / 学习 / 看电视 / 睡觉） |
| C | 换装 |
| T | 时间流速 ×1 / ×2 / ×4 / ×8 |
| M | 静音 / 开启声音 |
| H | 操作帮助 |
| 1 / 2 / 3 | 切换 生活区 / 金榜小学 / 奥园中央墅 |
| Esc | 关闭面板 / 关闭电视 / 结束小游戏 |

## 目录结构

```text
index.html            入口：importmap、canvas、启动页
styles/main.css       全部界面样式
src/main.js           主循环与总装
src/core/             渲染引擎、输入、时间系统、场景管理、互动、程序化音频
src/character/        主角建模与动画、换装、控制器
src/systems/          跳绳、投篮、电视、剧情任务链、存档
src/ui/               HUD、衣橱面板
src/world/            生活区、夜市、NPC
src/scenes/school/    金榜小学
src/scenes/home/      奥园中央墅
server.cjs            零依赖静态服务器
启动预览.bat          Windows 一键启动预览
```

完整的运行、改造、已知限制说明见 [使用教程.md](./使用教程.md)。
